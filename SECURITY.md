# Security policy

Report vulnerabilities to support@hugpy.ai. Do not open public issues for
security problems.

Include the affected distribution and version (`pip show hugpy-<name>`), a
reproduction, and the impact you observed. You will receive an acknowledgement
within three business days and a fix or mitigation plan within thirty.

Supported: the latest minor release line of every `hugpy-*` distribution and
`@hugpy/*` package. Older lines receive fixes only for actively exploited
issues.
