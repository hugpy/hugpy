# abstract_hugpy_dev (compatibility shell)

Transitional alias of the retired `abstract_hugpy_dev` monolith over the
thirteen `hugpy-*` distributions. It ships no implementation. Importing it
installs a meta-path finder that makes every old dotted path
(`abstract_hugpy_dev.flask_app.app.routes.chat_routes`, ...) resolve to the
*same module object* in its new home (`hugpy_server.app.routes.chat_routes`),
and re-exports the public names the old package root used to expose.

The full old-to-new table is in `RELOCATIONS.md`, regenerated by
`tools/generate.py`.

## Install

Dev-only, from the workspace checkout. Never publish this distribution:

```bash
./local_install.sh            # installs the hugpy-* packages and this shell editable
```

## Usage

```bash
abstract-hugpy-dev-check                 # import every aliased module, exit 1 on failure
abstract-hugpy-dev-check scan path/...   # list old imports in your code with their new targets
```

```python
import abstract_hugpy_dev.flask_app.app.routes.chat_routes as old
import hugpy_server.app.routes.chat_routes as new
assert old is new
```

## Architecture

See `PARTITION.md` at the repository root. This package is deleted once every
